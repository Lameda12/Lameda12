i build software and put it on the internet. cs @ dalhousie, halifax.

most of what's here started because something annoyed me and nobody had fixed it yet. i'd rather ship a rough version on a saturday than write a spec nobody reads. some of these worked. most didn't. that's the point.

---

## things i've shipped

**[aniscope](https://github.com/Lameda12/AniScoupe)** — anime discovery app. next.js, tailwind, shadcn. built it because every existing site is either dead or covered in ads.

**[commitcraft](https://github.com/Lameda12/commitcraft)** — cli that writes your commit messages. multi-provider, so you're not locked to one api. wrote it after typing "fix" for the four hundredth time.

**[microgpt-learning](https://github.com/Lameda12/microgpt-learning)** — gpt from scratch in pytorch. no libraries doing the interesting parts. you don't understand attention until you've debugged it at 2am.

**[poker4u](https://github.com/Lameda12/Poker4U)** — open source hold'em gto trainer.

**[my-llm-wiki](https://github.com/Lameda12/my-llm-wiki)** — notes from learning llms in public. apparently useful to other people too.

**[study-ops](https://github.com/Lameda12/study-ops)** — shell scripts that run my entire study setup. deeply unglamorous, saves me hours.

## how i work

next.js and python, plus whatever model api is cheapest and fastest this month. i change that opinion often.

i build alone, mostly. not on principle, it's just faster right now.

everything ships public, including the broken parts.
